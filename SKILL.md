# zk-ballot

zk-ballot is the Rust proof library behind Orkid's anonymous voting demos: Halo2 circuits for ballot validity, nullifiers for double-vote prevention, and on-chain verification targets.

## When to use

Studying or building ZK voting circuits, Halo2 gadgets, or anonymous tally systems.

## Install

```
cargo add zk-ballot
```
